## Description

RemoteOps is a remote system monitoring and management tool developed in C using TCP/IP socket programming for the IE3090 Network Programming assignment.

The system provides authenticated remote access to system information, process listing, restricted command execution, binary file transfer, and UDP-based monitoring. The implementation also includes a Throughput Measurement extension to measure the rate of data transfer.
